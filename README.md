# TrackTheDough
TrackTheDough is an Android Application that tracks the transaction that the user makes. 

# Installation
Prerequisite - You need to have a phone with developer settings enabled and you have to connect the phone to your system. 

## Steps
- Clone the project.
- Connnect your phone to the system.
- Use whatever IDE that you find suitable and check the devices to see if you are able to see your phone.
- If you are able to see your phone, then you can run ` .\gradlew.bat installDebug`
- The app should be installed in your phone now.
- Grant the SMS permission to the application and start using the app.
